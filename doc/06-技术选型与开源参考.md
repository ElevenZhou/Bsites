## 2. 候选项目速查

### 投稿 / 分发
- **biliup** — github.com/biliup/biliup ｜ 投稿 + 录播 + 搬运，Web + 多登录 + 多 P；可库化嵌入。
- **biliup-rs** — github.com/biliup/biliup-rs ｜ CLI 版，脚本化批量。
- **social-auto-upload** — github.com/dreammis/social-auto-upload ｜ 抖音/小红书/B站/视频号/TikTok 定时自动上传，多账号。
- **MultiPost** — multipost.app ｜ 浏览器扩展，一键多平台，自动适配规则。

### B站 API / 文档
- **bilibili-api**（Nemo2011） — nemo2011.github.io/bilibili-api ｜ 综合 API。⚠️ GPL v3 + 勿商用。
- **bilibili-API-collect**（SocialSisterYi） — socialsisteryi.github.io/bilibili-API-collect ｜ 接口大全文档。

### AI 内容生产
- **MoneyPrinterTurbo** — 关键词→成片，文案/素材/字幕/配乐/合成，多 LLM + 多 TTS，Web+API。
- TTS：**edge-tts**、**CosyVoice**、**GPT-SoVITS**、ChatTTS。
- 字幕：**Whisper** / **faster-whisper**。
- 数字人：**Heygem**、Wav2Lip、MuseTalk、SadTalker。

### 数据采集 / 观测
- **MediaCrawler** — 多平台公开数据采集（选题 / 竞品）。⚠️ 控频、ToS。
- **BiliOB** — UP 主 / 视频数据观测，指标体系参考。

## 3. ⚠️ 许可证与商用合规（关键）

| 依赖 | 许可证 | 商用风险 | 处理建议 |
|------|--------|----------|----------|
| bilibili-api | GPL v3 + 作者"勿商用"声明 | 🔴 高 | (a) 投稿改用 biliup；(b) 数据接口自研最小化；(c) 法务确认；不建议商用项目直接依赖 |
| biliup | 见仓库 LICENSE（须核实） | 待评估 | 确认许可证；库化使用评估传染性 |
| MoneyPrinterTurbo | 见仓库 LICENSE | 待评估 | 参考其设计，按需自研模块 |
| MediaCrawler | 见仓库 LICENSE + 仅供学习声明 | 中 | 仅采公开数据、控频、法务确认 |
| 指纹浏览器 / 代理 | 商业服务条款 | 中 | 走正规采购，留合规凭证 |

> **行动项（立项阶段必须完成）**：逐一核对每个拟用依赖的 LICENSE 文件与作者声明，输出《依赖许可证清单》附本文档；GPL / "勿商用"类依赖须法务给出明确可用 / 不可用结论。**未结论前不得写入生产代码**。

## 4. 自研 vs 复用 决策

| 部分 | 建议 | 理由 |
|------|------|------|
| 投稿底层 | 复用 biliup | 维护成本高、协议易变，交给社区 |
| 编排 / 调度 / 配置 / 后台 | **自研** | 业务核心、需贴合 100 账号矩阵管理 |
| 内容流水线 | 参考 MoneyPrinterTurbo **自研编排** | 需对接自家账号画像与审核 |
| B站数据接口 | 视许可证结论：自研最小接口 或 复用 | ⚠️ GPL 风险 |
| AI 子能力（TTS/字幕/LLM） | 复用成熟开源 / API | 无需重造 |
| 防关联环境 | 采购商业服务 | 自建不划算且难维护 |

## 5. 成本考量（待预算确认）

- LLM：文案 / 选题按量计费，100 账号规模需估算月调用量；可分级（贵模型只用于难任务）。
- TTS / 数字人：edge-tts 免费起步；数字人本地算力或 API，按垂类占比估。
- 算力：本地 GPU（Whisper / 数字人 / 自研模型）vs 云，按产能权衡。
- 环境：指纹浏览器 + 住宅代理按账号数线性增长，是规模化的主要可变成本之一。
- ⚠️ 在 [03 阶段0](./03-项目计划与里程碑.md) 输出成本模型，避免规模化后失控。
