# B站 AI 矩阵账号运营系统 · 文档中心

> 目标：用 AI + 自动化，像真人一样运营 **100 个** B站账号，把它们培养成各垂直领域优秀、专业的 UP 主。
> 核心能力：自动找寻素材 → 自动 / 半自动加工素材 → 自动 / 半自动投稿到指定账号 → 多账号矩阵化管理与养号。

本目录是项目的**单一事实来源（Single Source of Truth）**，用于沉淀调研成果、组织需求与计划、统一团队边界与任务。所有人在动手前先读本目录。

## 一句话项目概述

构建一套**配置驱动**的内容生产流水线与**多账号矩阵管理后台**：
运营人员只需维护"账号画像 + 内容策略 + 排期规则"，系统即可自动完成选题、素材采集、加工、合成、审核、投稿与数据回收，并在出现异常（限流 / 风控 / 需人工把关）时回退到人工环节。
