# 04 · 账号运营与养号策略

> 版本：v0.1（草稿）　|　关联：[01 PRD](./01-需求文档PRD.md)、[05 合规](./05-合规与风险管理.md)
> 核心理念：**像真人一样运营**——专业、稳定、有个性、不机械。质量与拟人化优先于数量与速度。

---

## 1. 运营哲学

> 我们不是"批量发垃圾内容的机器人农场"，而是"用 AI 放大优秀 UP 主运营能力的工作室"。

- **每个账号是一个独立的人设**，有清晰垂类、风格、价值主张。
- **内容对受众有用**：知识、信息、娱乐、审美——总要提供价值。
- **拟人化运营**：发布节奏、互动、成长曲线都接近真人，而非机械齐步走。
- **渐进可控**：宁可慢，不可被判定为营销号 / 低质号。

---

## 2. 账号分层与生命周期

```
注册 → 养号期 → 成长期 → 成熟期 →（持续运营 / 必要时休眠）
```

| 阶段 | 目标 | 行为特征 | 发布策略 |
|------|------|----------|----------|
| 养号期（前 1～4 周） | 建立"真实账号"信任 | 完善资料、浏览推荐、真实互动、少量发布 | 低频、高质，先发 1～3 条立人设 |
| 成长期 | 找到内容-受众匹配 | 稳定更新、关注数据、迭代选题 | 按垂类频率，观察爆款信号 |
| 成熟期 | 专业形象 + 稳定涨粉 | 风格固化、系列化内容 | 稳定排期，适度系列 / IP 化 |
| 休眠 | 风控 / 调整 | 暂停或降频 | 熔断触发或主动调整 |

> ⚠️ 养号期严禁"一上来狂发 / 引流 / 带货"，这是新号被封的高频原因。

## 3. 账号画像（Persona）配置模板

每个账号在策略服务中维护一份画像（JSON 化），示例字段：

```yaml
account:
  nickname: "示例·历史小课堂"
  vertical: "历史科普"            # 垂类
  audience: "对历史感兴趣的年轻人"  # 目标受众
  persona: "严谨但有趣的历史讲述者"  # 人设
  tone: "口语化、引经据典、不标题党"  # 风格
  content_form: ["口播", "图文混剪"]  # 内容形式
  frequency: "每周3条"
  publish_windows: ["19:00-22:00"]   # 偏好时段
  taboo: ["政治敏感", "未证实史料当定论"]  # 禁忌
  ref_accounts: ["参考优质同垂类UP"]   # 对标（学习非抄袭）
  series: ["冷门朝代系列", "成语背后的故事"]  # 系列规划
```

## 4. 内容策略

### 4.1 选题
- 来源：账号画像 + 平台热点 + 历史表现数据 + 系列规划。
- LLM 生成候选，运营把关；建立**选题库**避免重复。
- ⚠️ **跨账号去重**：同垂类多账号不得撞选题 / 撞脚本（用向量查重），否则易被判矩阵低质。

### 4.2 内容形式与垂类匹配（建议）
| 垂类示例 | 适配形式 | 产能方式 |
|----------|----------|----------|
| 资讯 / 知识科普 | 口播 / 数字人播报 | LLM 脚本 + TTS/数字人 + 字幕 |
| 影视 / 游戏二创 | 素材二创混剪 | ⚠️版权敏感，须授权 / 合理使用评估 |
| 生活 / 美食 / 教程 | 图文 / 实拍 | 半自动，人工素材为主 |
| 治愈 / 风景 / BGM | 无版权素材合成 | MoneyPrinterTurbo 式流水线 |

### 4.3 原创度与质量红线（⚠️）
- 杜绝纯搬运、跨账号复制粘贴、AI 痕迹过重的流水内容。
- 每条内容过**原创度 / 查重**，低于阈值退回重做。
- 标题不做"标题党 / 震惊体"；简介、标签规范。
- 宁缺毋滥：质量不达标不发。

---

## 5. 拟人化发布规则

- **错峰**：跨账号不同时段发布，避免整点齐发。
- **抖动**：在偏好时段内加随机分钟级抖动。
- **节奏**：单账号频率符合人设（每周 2～4 条为主），不忽高忽低。
- **互动**：适度真实互动（回复评论等），但不刷量、不机器水评。
- **作息**：模拟真人活跃时段，深夜不密集操作。

---

## 6. 数据驱动迭代

- 监控指标：播放、完播、点赞、评论、转发、涨粉、粉丝画像。
- 复盘节奏：周维度看账号，单条看爆 / 平 / 差原因。
- 反哺：好选题 / 好形式加权，差的下线；A/B 标题与封面。
- ⚠️ 异常下跌（疑似限流）→ 触发熔断 SOP（见 §7）。

---

## 7. 账号健康与熔断 SOP

**健康度信号**：发布成功率、播放是否异常骤降、是否收到平台提醒 / 处罚、登录态是否频繁失效。

**熔断触发 → 处置**：
1. 系统标记账号为"异常"，暂停其排期与在途任务。
2. 告警通知运营。
3. 人工排查：是内容问题？关联问题？账号问题？
4. 整改后小步恢复（降频试发），观察再放量。
5. 记录事件，沉淀到风控规则。

> ⚠️ 一个账号出问题时优先**隔离**，排查是否环境 / 关联导致连锅，防止波及矩阵。

---

## 8. 人工在环（什么必须人审）

- 养号期内容、敏感垂类、风险分中高的稿件、二创版权存疑内容、首次系列内容 → **必须人工审核**。
- 自动化只承担"产能与重复劳动"，**判断与把关留给人**。
